## 项目审查与修复（WP Clean Admin）

### 审查发现
- P0 严重：AJAX nonce 字段名不统一。11 个 handler 用 `$_POST['nonce']`（settings/dashboard/cleanup），11 个用 `$_POST['_wpnonce']`（database/resources/reset/performance/menu/diagnostics/user-roles）。前端 JS 用 `_wpnonce`，致前一类永远校验失败。
- P1：`includes/ajax/settings-ajax.php` 的 `save_settings` 直接 `update_option` 未 sanitize（存储型 XSS 风险）。
- P1（历史）：65 个文件 `@version` 注释仍为 1.8.0，仅 autoload.php 是 1.8.1（update_versions.php 未实际执行）。
- P2：11 个 AJAX 文件各自内联重复 WP 函数 stub。

### 修复动作（已落地）
1. 统一 nonce 字段名为 `_wpnonce`（前端本就用 `_wpnonce`，故改 settings/dashboard/cleanup 三文件共 11 处）。
2. settings-ajax.php 新增 `private static sanitize_settings()` 递归清理，save_settings 调用之。
3. 全量同步版本号 1.8.1 → **1.8.2**（主文件 Version/WPCA_VERSION、65 注释、JS、3 个 .po/.pot），用 .NET API 避免 BOM 污染。
4. 删除 11 个 AJAX 文件内联 stub，统一依赖 autoload.php 已加载的 wpca-wordpress-stubs.php。
5. 新增 phpunit.xml.dist、tests/bootstrap.php、tests/HelpersTest.php、tests/SettingsAjaxTest.php（覆盖 sanitize/nonce/format_bytes）。
6. CHANGELOG 新增 1.8.2 条目。
