## 创建插件原型与设计规范

用户要求"创建插件原型和设计规范"。按 openspec 流程在 `openspec/changes/plugin-prototype/` 建提案三件套：
- proposal.md：变更原因（架构冗余/前端无规范/缺可验证原型）、内容、影响、计划
- tasks.md：五阶段任务清单
- design.md：设计规范（架构分层终结双架构、统一 AJAX 网关、前端交互规范、安全基线、UI/UX 设计语言）

产出物（存入资产，未改主代码）：
- PHP 原型骨架：`wpcleanadmin/assets/prototype/php/`
  - class-wpca-module-base.php（抽象基类 Module_Base，单例 + register_ajax + sanitize_settings）
  - class-wpca-ajax-gateway-base.php（统一 nonce 字段名 _wpnonce + action wpca_ajax_nonce + capability manage_options）
  - class-wpca-module-dashboard.php（示例模块，演示标准写法）
- 前端 UI 原型：`wpcleanadmin/assets/prototype/ui/`
  - settings-page.html（WP 原生基底 + BEM .wpca-*，含 wp_nonce_field('_wpnonce')）
  - settings-page.css（:root 变量 + 782px 响应式断点）
  - settings-page.js（FormData 自动携带 _wpnonce，fetch 标准用法）
- 测试：`wpcleanadmin/tests/PrototypeTest.php`（手动 require 原型，验证抽象类/单例/网关）

关键设计决策：
- 以 `includes/modules/**/class-wpca-*.php` 为唯一权威实现，旧 `includes/class-wpca-*.php` 标 @deprecated 后续删
- 所有 AJAX 必须继承 Gateway_Base，字段名固化 `_wpnonce`（根治 1.8.2 nonce 不一致 bug）

注意：原型文件在 assets/，不在 includes/，不被现有 autoload 加载（有意隔离）；测试手动 require。本机无 php CLI，未实跑 composer test。
