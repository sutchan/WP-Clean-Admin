# WP Clean Admin 设计规范（高保真）

版本：1.8.2 基线
最后更新：2026-08-08

## 1. 产品定位与信息架构

WP Clean Admin 是 WordPress 后台清理与优化插件，目标用户为站点管理员。
信息架构（IA）以**单一顶级菜单**为入口，下设 6 个一级功能页：

```
WP Clean Admin（顶级菜单）
├─ 仪表盘 Dashboard      总览 + 一键体检
├─ 清理 Cleanup          数据库/媒体/评论/内容清理
├─ 性能 Performance       资源与加载优化
├─ 安全与菜单 Security    菜单定制 + 权限 + 登录优化
├─ 数据库 Database        表管理 + 备份/恢复
└─ 诊断 Diagnostics       环境检测 + 报告
└─ 设置 Settings          全局配置
```

设计原则：
- 每页左侧为功能导航 tab，右侧为内容区（WP 后台惯用布局）
- 危险操作（删除/重置）必须二次确认 + 显示影响范围
- 所有写操作经 AJAX 网关（nonce + capability）

## 4. 交互规范

### 4.1 AJAX 数据流
```
前端 submit ──► FormData(含 _wpnonce) ──► Gateway_Base.dispatch()
  ├─ wp_verify_nonce(_wpnonce, 'wpca_ajax_nonce')  → 失败 403 invalid_nonce
  ├─ current_user_can('manage_options')            → 失败 403 forbidden
  └─ call_user_func(handler) ──► wp_send_json_success/error
前端收到响应 ──► 更新 UI / 显示 toast
```
- 加载态：按钮 disabled + spinner
- 失败：toast 红色 + 表单保持
- 成功：toast 绿色 + 数据刷新

### 4.2 危险操作二次确认
- 删除/重置类按钮点击 → `.wpca-modal` 弹出，显示"将影响 N 条记录"
- 确认后才发起 AJAX

### 4.3 空状态与错误态
- 无数据：`.wpca-empty`（图标 + 文案 + 引导按钮）
- 加载失败：`.wpca-error`（重试按钮）

## 5. 可访问性（WCAG AA）

- 所有交互元素可键盘聚焦，焦点环 `--wpca-primary`
- 表单 label 关联 input（`for`/`id` 或包裹）
- 状态变更用 `aria-live="polite"` 区域播报
- 颜色不作为唯一信息载体（徽标配文字）
- 弹窗 `role="dialog"` + `aria-modal="true"` + Esc 关闭 + 焦点陷阱

## 6. 编码与目录规范

- 命名空间：`WPCleanAdmin\Modules\<Domain>\Classes\Module_<Name>`
- 模块继承 `Module_Base`；AJAX 经 `Gateway_Base`
- 所有输出 `esc_*`；所有输入 `sanitize_*`；SQL `$wpdb->prepare`
- 文件头标注 `@package` / `@version`；中文注释关键逻辑
