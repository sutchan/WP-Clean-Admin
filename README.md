## 为什么选择 WP Clean Admin？

您的 WordPress 后台是否看起来乱糟糟的？有太多不需要的菜单项、小工具和功能？WP Clean Admin 可以帮您：

- **清理混乱**：隐藏不必要的菜单、小工具和冗余信息
- **提升速度**：禁用不需要的功能，让后台飞起来
- **增强安全**：保护您的网站免受常见安全威胁
- **简化管理**：让后台界面更符合您的需求

---

## 核心功能

### 🧹 后台清理
- **菜单精简**：隐藏不需要的后台菜单项，让界面更清爽
- **仪表盘优化**：移除不需要的仪表盘小工具
- **登录页美化**：自定义登录页面外观
- **顶部栏清理**：隐藏顶部管理栏中不需要的项目

### 🚀 性能优化
- **禁用表情符号**：移除 WordPress 表情符号功能，加快加载
- **优化资源**：压缩和合并 CSS/JS 文件
- **预加载资源**：预先加载关键资源，提升体验
- **控制心跳**：禁用或调整 WordPress 心跳 API 减少服务器负载

### 🔒 安全增强
- **隐藏版本**：移除 WordPress 版本信息，防止针对性攻击
- **登录保护**：添加验证码，防止垃圾登录
- **双重验证**：支持两步验证，增加账户安全
- **登录限制**：限制登录尝试次数，防止暴力破解
- **访问控制**：按角色限制后台访问权限

### 🎛️ 菜单定制
- **角色权限**：根据用户角色显示/隐藏菜单
- **菜单排序**：自定义后台菜单的排列顺序
- **创建分组**：将相关菜单组织成自定义分组
- **顶部栏定制**：自定义顶部管理栏显示内容

### 💾 数据库管理
- **一键优化**：自动优化数据库表
- **备份恢复**：轻松创建和下载数据库备份，随时恢复
- **智能清理**：清理临时数据、孤立元数据和过期计划任务

## 快速开始

### 安装方法

1. 下载插件 ZIP 文件
2. 在 WordPress 后台，进入「插件 > 添加新插件」
3. 点击「上传插件」，选择您下载的 ZIP 文件
4. 点击「现在安装」，然后点击「激活」

或者您也可以通过 FTP 上传到 `wp-content/plugins/` 目录，然后在后台激活。

### 3 步上手

1. **访问设置**：激活后，在左侧菜单找到「WP Clean Admin」
2. **配置功能**：使用选项卡式界面，根据需要启用各项功能
3. **保存生效**：点击「保存设置」，插件立即开始工作！

## 使用指南

### 设置页面
- 访问 **设置 > Clean Admin** 配置插件
- 使用顶部选项卡切换不同功能模块
- 每次更改后记得保存

### 数据库管理
- 进入 **设置 > Clean Admin > 数据库**
- 点击「优化数据库」自动优化表
- 点击「备份数据库」创建备份
- 需要时点击「恢复数据库」进行恢复

### 清理操作
- 进入 **设置 > Clean Admin > 清理**
- 选择您想运行的清理选项
- 点击「运行清理」开始清理过程

### 性能优化
- 进入 **设置 > Clean Admin > 性能**
- 开启/关闭各项优化选项
- 保存设置立即生效

### 安全设置
- 进入 **设置 > Clean Admin > 安全**
- 根据需要启用安全功能
- 保存设置后立即生效

## 原型与设计系统

本项目附带高保真可交互原型与设计规范，便于设计与验收：

- **原型**（`prototype/`）：`ui/index.html` 单入口（shadcn 风格），内置真实 mock 数据；
  `php/` 为模块骨架（Module_Base + AJAX 网关），与插件运行代码解耦。
  直接用浏览器打开 `prototype/ui/index.html` 预览，无需后端。
- **设计系统**（`prototype/ui/wpca-components.css`）：shadcn/ui 风格单一令牌来源，
  含设计令牌（色彩/字体/间距/圆角/阴影/动效）、组件库（card/btn/badge/switch/table/modal/toast 等）、
  交互标准与响应式规范。插件 `wpcleanadmin/assets/css/wpca-admin.css` 末尾引用同源同名类。
- **设计规范**：[`docs/设计规范_20260808.md`](docs/设计规范_20260808.md)
- **审计报告**：[`docs/审计报告_20260808.md`](docs/审计报告_20260808.md)
- **OpenSpec 规范**：[`openspec/`](openspec/) — 功能提案与规范文档
